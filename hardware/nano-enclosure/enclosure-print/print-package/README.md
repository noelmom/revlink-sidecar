# RevLink Sidecar Nano print package

This folder contains exactly three printable part sets. Each is supplied in
both STL and 3MF format.

## 01 — Bottom

- `01-revlink-sidecar-nano-bottom.stl`
- `01-revlink-sidecar-nano-bottom.3mf`

One watertight body, 55 × 55 × 5.6 mm.

## 02 — Top with OLED and USB-C-side controls

- `02-revlink-sidecar-nano-top-oled-usbc-controls.stl`
- `02-revlink-sidecar-nano-top-oled-usbc-controls.3mf`

One watertight body, 55 × 55 × 31 mm. This is the corrected lid with the
centered OLED opening, concealed Ethernet jack, accessible USB-A and USB-C,
and two guided openings for the side-actuated RST and BOOT buttons.

## 03 — USB-C-side RST/BOOT button pair

- `03-revlink-sidecar-nano-usbc-side-buttons-pair.stl`
- `03-revlink-sidecar-nano-usbc-side-buttons-pair.3mf`

Two watertight button bodies arranged as a pair. The buttons are identical;
install one over RST and one over BOOT on the USB-C edge.

The 3MF versions are preferred for sending to the print service because they
record millimeter units explicitly.
